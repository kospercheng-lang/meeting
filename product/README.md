# Gate-to-Market（完整產品）

把 ISTI GTM 方法論 v0.98、SParta+ 產業情報、客戶專區、分析師工作台與定價試算整合成一個網頁應用。三種角色共用同一份案件資料。

| 角色 | 能做什麼 |
| --- | --- |
| 訪客 | 看首頁與產業情報、申請前自評、送出申請（自動建立「申請中」案件並帶入候選情境） |
| 客戶 | 確認段 0 設定、填窗口與決策人、提供訪談對象與資料、確認技術基準、校準候選情境、看週報與閘門結果 |
| 分析師 | 案件總覽、段 0 備忘錄、技術基準與情境池、假設與證據、兩道閘門裁決、推進段（閘門未過無法跨段）、週報、工時、定價試算 |

## 檔案

- `src/app.html`：唯一的原始碼。
- `build.py`：產生 `dist/artifact.html`（claude.ai 版）與 `index.html`（任何靜態主機可用）。
- 修改後執行 `python3 build.py`。

## 資料存放

- 在 claude.ai 開啟：使用共用資料庫，組織內能開啟此頁的人看到同一份資料。
- 其他地方開啟 `index.html`：示範模式，資料只存在該瀏覽器；開兩個分頁分別當客戶與分析師，即可走完整流程。
- 角色切換只是示範，不是權限控管。要讓外部客戶正式登入，需要有帳號系統與後端資料庫的主機。

產業情報數值、候選情境與範例案件為示意資料；價格為待首案校正的假設。
