# Gate-to-Market 產品化素材

把《ISTI GTM 策略顧問方法論 v0.98》包裝成可銷售產品的素材。

| 檔案 | 內容 |
| --- | --- |
| `GTM_定價模型.xlsx` | 三個服務包的工時與價格試算（假設值以藍字黃底標示，開檔時自動重算） |
| `gate-to-market.html` | 產品介紹網頁原始檔 |
| `gtm-client-portal.html` | 客戶專區示範版原始檔（客戶視角操作頁，資料只存在瀏覽器） |
| `gtm-workbench.html` | 案件工作台原始檔（需在 claude.ai 開啟才能存取資料庫） |

所有價格與工時都是待首案校正的假設，混合費率暫定每小時 NT$3,500，不是本所正式費率。
